# Beveiligingsbeleid

## Een kwetsbaarheid melden

Meld kwetsbaarheden **niet** via een openbaar issue. Gebruik in plaats daarvan [GitHub Private Vulnerability Reporting](https://github.com/psinke1974/fris-alcoholmanagement/security/advisories/new) van deze repository.

Beschrijf het probleem, hoe het te reproduceren is en wat de mogelijke impact is. Je krijgt binnen een week een reactie.

## Reporting a vulnerability (English)

Please do **not** open a public issue. Use [private vulnerability reporting](https://github.com/psinke1974/fris-alcoholmanagement/security/advisories/new) on this repository instead.

## Ondersteunde versies

Alleen de laatste versie op de `main`-branch krijgt beveiligingsupdates.
